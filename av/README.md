# tensorcodec-av

FFmpeg extension behind [TensorCodec](https://github.com/MilkClouds/tensorcodec)'s
`VideoDecoder` and `AudioDecoder`; install `tensorcodec`, which depends on the matching version.
Bundled library licenses: [`licenses/README.md`](https://github.com/MilkClouds/tensorcodec/blob/main/av/licenses/README.md).
